# Gap Pullback · Paper

Find the native screen under **Research → Gap Pullback · Paper**. It displays the backend-generated five-stock pilot (through 25 September 2026), annual/per-stock results, sensitivity, trade fees, monthly equity and coverage, followed by a separate current paper account section with shortlist, setups, signals, positions, trades, rejections and recent equity.

This screen is read-only. Pull down to refresh. Account status refreshes every 15 seconds while focused; background polling is disabled. It never starts an observer or sends an order/control request. Existing authenticated `request()` handling is used, including session expiry.

Backend routes:
- `/api/research/gap-paper/pilot`: sanitized saved research snapshot.
- `/api/research/gap-paper`: current account/status, independent of the historical pilot.

If the backend is unavailable or has not received the update, the dated bundled pilot remains visible and is labelled as a snapshot. Current-account failures are shown, not replaced with historical performance or fabricated activity. The fallback JSON is an exact copy generated by the dashboard's `research/gap_paper/publish_view.py`; no signal or performance computation is implemented in mobile.

From the sibling dashboard repository, refresh both copies with:

```sh
python3 -m research.gap_paper.publish_view --mobile-output ../nse-mobile/assets/data/gapPaperPilot.json
```

Local development uses the existing `EXPO_PUBLIC_API_BASE` setting and normal Expo workflow. An emulator/device must be able to reach the configured backend. No API address, authentication setting, trading service or deployment setting was changed. These changes need the normal reviewed app/backend release to appear in an existing installed production app.
